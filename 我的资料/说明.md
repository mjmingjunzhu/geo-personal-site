# 我的资料（把你的资料放在这里）

这个文件夹是给你放资料的。放好之后，让 AI 助手来读，它会把内容填进网站。

## 可以放什么

任何能说明「你是谁、在做什么」的东西都可以，格式不限：

| 资料 | 举例 | 必需吗 |
|---|---|---|
| 自我介绍 | 简历（Word / PDF）、一段文字、公众号或朋友圈里的介绍截图 | 必需 |
| 联系方式 | 邮箱（必需），微信号、公众号名称、抖音 / 小红书 / GitHub 主页链接 | 邮箱必需 |
| 正在做的事 | 2～4 件，一句话说清每件是什么、帮谁解决什么问题 | 建议 |
| 项目 | 正在做或做过的项目介绍、链接、截图 | 建议 |
| 文章 | 写过的文章（Word、txt、Markdown 或公众号文章链接都行），至少一篇 | 建议 |
| 照片 | 一张本人照片（竖版最好）、一张头像（正方形） | 建议 |
| 微信二维码 | 微信「我 → 个人信息 → 我的二维码」截图 | 可选 |
| 域名、备案号 | 有就写，没有可以先空着 | 可选 |

## 两种放法，选一种就行

1. **直接把文件丢进这个文件夹**：简历、照片、文章、截图都行，文件名随便起。
2. **照着 `填写清单.md` 填空**：用记事本或任何文本编辑器打开，在每个问题下面写你的回答。

两种也可以一起用。

## 放好之后

回到项目最外层，打开 `交给AI的提示语.txt`，把「第二句：换成你的内容」那段话复制发给你的 AI 助手。

## 关于隐私

这个文件夹里的东西只在你自己的电脑上，不会自动上传到任何地方。
如果你以后用 Git 把网站上传到 GitHub，这个文件夹里除了这两份说明文件，其他东西默认都不会被上传（已经写进 `.gitignore`）。
注意：`填写清单.md` 本身会被上传。如果你不想公开填写的内容，就复制一份改名（例如 `我的回答.md`）再填，原来那份保持空白。
